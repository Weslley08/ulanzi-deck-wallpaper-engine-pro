# Wallpaper Engine PRO for Ulanzi D200

Open-source integration of Wallpaper Engine with Ulanzi Studio, following the structure and quality practices of [Clima PRO](https://github.com/Weslley08/ulanzi-deck-clima-pro).

**Status: development bootstrap / not installable yet.** We are validating the official Wallpaper Engine CLI and Ulanzi SDK before producing a plugin ZIP or publishing a release.

See `docs/PHASE-1.md` and `docs/BENCHMARK.md` for the next implementation and the CMR + RTK experiment.
